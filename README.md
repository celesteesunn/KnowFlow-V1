# KNOWFLOW — Enterprise Knowledge & Collaboration Platform

KnowFlow centralises organisational documents and provides simple AI-powered,
document-based question answering. Employees can log in, create/view projects,
upload PDF documents, search them, ask an AI assistant questions grounded in the
document content, see the source document/page used for each answer, and detect
potentially duplicate documents.

> **Status:** Chunk 1 (foundation) and Chunk 2 (all features) are implemented
> and verified end-to-end.

## The problem it solves

Organisational information is scattered across documents, making it hard for
employees to find information quickly. KnowFlow centralises these documents and
provides simple AI-powered document-based question answering.

## Features

- **Authentication** — register, log in, log out (session cookies, hashed passwords)
- **Projects** — create and view knowledge projects
- **PDF upload** — upload PDFs; text is extracted per page with PyPDF
- **Search** — keyword search across a project's documents with snippets
- **AI question answering** — ask questions; the answer is grounded in the
  documents and cites the source document + page used
- **Duplicate detection** — TF-IDF cosine similarity flags near-identical documents

### AI mode

- With `OPENAI_API_KEY` set, answers are generated by an OpenAI-compatible LLM
  (configurable base URL + model) using only the retrieved passages.
- Without a key, KnowFlow runs in **retrieval-only mode**: it returns the most
  relevant passages with source citations, so the feature is fully usable offline.

## Setup

### 1. Backend (Flask)

```bash
cd backend
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r requirements.txt
python app.py                   # starts on http://localhost:5000
```

Optional AI configuration (environment variables):

```bash
set OPENAI_API_KEY=sk-...       # enables LLM-generated answers
set OPENAI_BASE_URL=https://api.openai.com/v1   # or any OpenAI-compatible endpoint
set OPENAI_MODEL=gpt-4o-mini
set KNOWFLOW_SECRET_KEY=change-me   # session signing key
```

### 2. Frontend (React)

```bash
cd frontend
npm install
npm run dev                     # starts on http://localhost:5173
```

Open http://localhost:5173, register an account, create a project, upload PDFs,
then search, ask questions, and check for duplicates.

## API

| Method | Endpoint                              | Description                          |
| ------ | ------------------------------------- | ------------------------------------ |
| GET    | `/api/health`                         | Service status, version, DB check    |
| POST   | `/api/auth/register`                  | Create account (sets session)        |
| POST   | `/api/auth/login`                     | Sign in (sets session)               |
| POST   | `/api/auth/logout`                    | Sign out                             |
| GET    | `/api/auth/me`                        | Current user (or null)               |
| GET    | `/api/projects`                       | List projects + document counts      |
| POST   | `/api/projects`                       | Create project                       |
| POST   | `/api/projects/<id>/documents`        | Upload a PDF (multipart `file`)      |
| GET    | `/api/projects/<id>/documents`        | List documents in a project          |
| GET    | `/api/projects/<id>/search?q=…`       | Keyword search with snippets         |
| POST   | `/api/projects/<id>/ask`              | AI Q&A → answer + source citations   |
| GET    | `/api/projects/<id>/duplicates`       | Near-duplicate document pairs        |

All endpoints except `/api/health` and `/api/auth/*` require an authenticated
session.
